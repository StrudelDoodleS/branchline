# Contributing to Branchline

Open issues and pull requests at [StrudelDoodleS/branchline](https://github.com/StrudelDoodleS/branchline). Target the default `phone-controls` branch and describe the visible behavior being changed.

Run the root and extension tests, both TypeScript checks, and the relevant browser checks listed in [README.md](README.md). Include a portrait screenshot for visual changes.

Keep changes focused and retain upstream attribution. Contributions to this fork use the repository's [Apache 2.0 license](LICENSE). The retained [CLA.md](CLA.md) describes the original project's contribution process; contributions sent to upstream should follow upstream's guidelines.
